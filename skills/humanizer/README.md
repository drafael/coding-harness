# Humanizer Skill

## Description
Edits text to remove common AI-writing patterns and make output sound more natural, specific, and human-written while preserving meaning and intended tone.

## Usage Examples
- "Humanize this draft and remove AI-sounding phrasing."
- "Rewrite this release note to sound more natural and less formulaic."
- "Keep the same meaning, but make this paragraph read like a real person wrote it."
- "Clean this generated content and match my writing style."
