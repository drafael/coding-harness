# OWASP Security Skill

## Description
Applies OWASP security guidance during code review and implementation, with practical checks for authentication, authorization, input handling, secure coding patterns, and AI-agent security risks.

## Usage Examples
- "Review this code for OWASP Top 10 vulnerabilities."
- "Check this auth flow against ASVS 5.0 requirements."
- "Audit this API for input validation and access-control flaws."
- "Assess this agent workflow for OWASP Agentic AI risks."
