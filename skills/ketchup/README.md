# Ketchup

Summarizes chat progress and every decision or action still waiting on the user.

## Usage

```text
/ketchup
```

In Claude Code, use `/ketchup`; in Pi, use `/skill:ketchup`. In OpenCode, ask “Use the ketchup skill”; `/ketchup` is available only when the skill's `opencode/slash` metadata is enabled.
