# Pretty Mermaid Skill

## Description
Renders Mermaid diagrams as themed SVG or ASCII output for documentation, architecture notes, and terminal-friendly visualization.

## Usage Examples
- "Render this Mermaid diagram using `tokyo-night` theme."
- "Create a sequence diagram for this API flow and export SVG."
- "Batch-render all `.mmd` files in `docs/diagrams`."
- "Generate an ASCII version of this flowchart for terminal output."
