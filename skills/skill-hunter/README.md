# Skill Hunter Skill

## Description
Discovers and recommends external skills for a project by analyzing stack and goals, comparing trusted sources, and proposing a minimal install-ready skill stack.

## Usage Examples
- "Find the best external skills for this project."
- "Recommend skills for TypeScript testing and CI automation."
- "Compare external options for debugging and security workflows."
- "Build a skill stack for this repo and explain trade-offs."
