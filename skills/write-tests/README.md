# Write Tests Skill

## Description
Creates unit and integration tests that follow project conventions, validate critical behavior, and improve reliability.

## Usage Examples
- "Write unit tests for this service class."
- "Add integration tests for this API endpoint."
- "Create tests for edge cases and error handling in this function."
- "Add missing tests to improve coverage for this module."
