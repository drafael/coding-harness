# Test Coverage Skill

## Description
Analyzes existing test coverage, identifies gaps, and improves line/branch/function coverage with meaningful test strategy and prioritization.

## Usage Examples
- "Analyze test coverage and show critical gaps."
- "Improve branch coverage in auth and billing modules."
- "Set up coverage reporting and thresholds in CI."
- "Find untested critical paths and propose tests."
