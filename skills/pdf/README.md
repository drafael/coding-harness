# PDF Skill

## Description
Handles end-to-end PDF workflows: text/table extraction, merge/split/rotate, watermarking, OCR for scanned PDFs, image extraction, encryption/decryption, and PDF form filling.

## Usage Examples
- "Extract all text and tables from this PDF."
- "Merge these three PDFs into one file."
- "Split this PDF into one file per page."
- "Fill this PDF form using the provided field values."
