# Wrong Skill

## Description
Reset-and-rethink skill used when the user rejects the assistant’s current answer, implementation, plan, or problem-solving direction. It reframes the core problem, surfaces missing context, proposes fresh options, and recommends the best next path with trade-offs.

Use `clarify` instead when the user reports that the system, configuration, or documentation behaves incorrectly and wants an evidence-backed explanation.

## Usage Examples
- "Your approach is wrong. Start over and propose better options."
- "The implementation you suggested still fails; give me 2-3 fresh paths."
- "Discard the previous answer and try again from first principles."
- "This solution is headed in the wrong direction; re-evaluate it with trade-offs."
