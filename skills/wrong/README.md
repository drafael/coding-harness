# Wrong Skill

## Description
Reset-and-rethink skill used when the current implementation direction is failing. It reframes the core problem, surfaces missing context, proposes fresh options, and recommends the best next path with trade-offs.

## Usage Examples
- "Wrong approach — start over and propose better options."
- "This isn’t working; give me 2-3 fresh implementation paths."
- "Try again from first principles and recommend the best path."
- "Bad direction, re-evaluate this solution with trade-offs."
