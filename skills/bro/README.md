# Bro

Restates the assistant's last answer in plain, concise language.

## Usage

```text
/bro
```

In Claude Code, use `/bro`; in Pi, use `/skill:bro`. In OpenCode, ask “Use the bro skill”; `/bro` is available only when the skill's `opencode/slash` metadata is enabled.
