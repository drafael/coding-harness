AUTOPILOT · STATE MODEL

Waiting is durable; stopping is terminal

Operator pause, provider checks, and unknown executor state share one nonterminal run state without sharing the same recovery rule.

Pause accounting

A pause-cancelled launch stays in history but is not charged. A naturally completed attempt racing with pause is charged.

Provider waiting

Heartbeats are not journaled. Session expiry remains waiting, and every resume reobserves the exact PR/MR, head, base, state, and checks.
