# In your own words

Restates the user's goals and underlying problem to check understanding before solving it.

## Usage

```text
/in-your-own-words
```

In Claude Code, use `/in-your-own-words`; in Pi, use `/skill:in-your-own-words`. In OpenCode, ask “Use the in-your-own-words skill”; `/in-your-own-words` is available only when the skill's `opencode/slash` metadata is enabled.
